# 論文サーベイ & 月次フロンティアレポート作成スキル

以下の手順に従って、特定分野の最新論文フロンティアレポートを作成してください。

## 実行手順

1. **論文データの取得**
   - 以下のシェルコマンドを実行して、最新論文データのJSONファイル `temp_papers.json` を生成してください。
     ```bash
     python fetch_papers.py > temp_papers.json
     ```

2. **データの解析と要約**
   - `temp_papers.json` を読み込み、各論文の内容を分析してください。
   - 特に以下の観点に着目して整理してください：
     - 論文ごとに該当する **JEL分類コード** を明記してください。
     - 研究のコアとなる問題意識（Research Question）
     - 提案・適用されている手法やフレームワーク
     - 学術的・実証的な主な貢献

3. **レポートの作成と保存**
   - 取得した情報を整理し、**プロジェクトのルートディレクトリ直下**にある `reports/` ディレクトリ配下に `YYYY-MM_frontier_report.md` （例: `./reports/2026-08_frontier_report.md`）として出力してください。
   - レポートのフォーマットは以下のテンプレートに従ってください。

---
